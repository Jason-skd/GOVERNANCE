# SemVer Milestones

Create milestones only for planned release versions such as `v1.4.0`. Do not
invent due dates; add one only when the repository has a real release
commitment.

A release milestone contains leaf deliverables and bugs targeted to that
version. Direction and governance work remain outside milestones, as do pull
requests. Pull requests close the leaf work through `Closes` references.

Before closing a milestone, confirm that every included item is closed by
evidence for the released revision or explicitly moved to another version.
